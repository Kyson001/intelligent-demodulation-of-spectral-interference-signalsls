# 整个课题的复现思路与操作步骤

研究对象：迈克尔逊干涉仪。目标：由光谱联合估计光程差与参考波长处的相位。当前已完成数据准备、传统算法伪标签、不用CNN的MLP与LSTM训练及验证比较；多种子/独立真值验证、网页和PPT属于后续实施部分。

## 1. 下载与环境

```powershell
git clone https://github.com/Kyson001/intelligent-demodulation-of-spectral-interference-signalsls.git
cd intelligent-demodulation-of-spectral-interference-signalsls
python -m pip install -r requirements-repro.txt
python -m pytest tests -q
python -X utf8 scripts/verify_repository_data.py
```

`requirements-repro.txt`记录已测试的直接依赖版本；当前验证环境为Windows、Python 3.13.5。`requirements.txt`是较宽松的依赖要求。普通Git下载即包含原始CSV与三份NPZ，无需额外的数据下载工具。

## 2. 直接使用现成训练/验证/测试数据

`datasets/processed/`中已有train、validation、test三个NPZ，分别为2800、600、600条，输入维度2048。读取字段见`datasets/README.md`。

顺序核查支持从第一条开始每10条一组，共400个位置；固定种子20261117按位置70/15/15划分。跨位置完全重复谱也不会跨分区。分组不是按单条样本随机打乱。

OPD、中心相位均是伪标签。OPD有效3999条，相位有效3992条；5条位置一致性提示与8条标签复核记录保留。使用各自mask选取损失目标，不通过NaN×0处理无效目标。

## 3. 一键从原始数据重算当前链路

```powershell
python -X utf8 scripts/reproduce_data_pipeline.py
```

输出到新的`analysis/reproduction/`，不覆盖仓库已发布数据。若输出目录存在，使用新的目录：

```powershell
python -X utf8 scripts/reproduce_data_pipeline.py --out analysis/reproduction_run2
```

执行顺序：仓库数据哈希核对 → C预处理 → 多峰OPD与局部相位伪标签 → 顺序审计 → 按位置划分 → 数组/掩码/分区一致性核对。原始CSV不再复制到重建包，避免无意义重复占用空间。

不同平台/线性代数库可能导致微小浮点差异；重新生成的NPZ字节哈希不一定跨环境相同。应同时核对数值、sample_id、位置清单、有效掩码及划分，而非仅比较重算文件字节。

## 4. C方案：输入怎么得到

原始波长与强度 → 单位检查 → k=2π/λ并排序 → 10001点等k线性插值 → 高斯慢变背景估计（σ=100） → 扣背景并除受限包络代理（下限8%） → 周期Hann → 多相抗混叠至2048点 → 逐谱去均值/RMS归一化。

代码：`scripts/preprocess_c.py`，逐块中文讲解见文档05。高斯核用于背景估计，Hann用于加窗，两者不是温漂补偿。当前沿用采集数值，不根据列名盲目执行dBm转换。

## 5. OPD与相位伪标签

近似无色散时δ=c/Δf。Δf取多个相邻干涉峰的频率间距稳健拟合值，不是Δλ，不是光频梳梳齿间隔，也不是“文件编号×10 μm”。

制标签使用未降采样的光谱。FFT做粗定位，精确峰位在加Hann之前的包络补偿谱上细化，避免窗函数移动局部极值。实际有色散时，全带间距对应有效平均群OPD，不无条件等同几何位移。

中心相位：正侧带 → IFFT → 去整数载波 → 解包裹余相位 → 1560 nm附近局部二次拟合 → 包裹到圆周范围。保存sin/cos，并由峰位截距相位作交叉检查。没有恢复未知整周期编号，也没有证明绝对相位零点。

代码：`src/demodulation/pseudo_labels.py`与`scripts/generate_pseudo_labels.py`，详细说明见文档06。

## 6. 分组和质量复核

代码：`scripts/split_dataset_by_position.py`，文档07。

同位置10条重复只用来建立分组；不默认平均，防止相位变化削弱条纹。3处跨位置完全重复涉及的位置绑定到同分区。位置异常记录不凭伪标签自动重新归属。

本次是同次采集随机留出位置，验证/测试各有10条位于训练OPD范围外的边界记录。不能把该划分称为跨设备、跨日期或专门设计的连续区间外推验证。

## 7. 不用CNN的神经网络实现

按当前要求不使用CNN。已经实现共享全连接层加双任务头的MLP教学基线，以及光谱块双向LSTM；手把手代码和运行说明见[文档09](09_不用CNN的联合解调网络手把手教程.md)和[文档10](10_LSTM联合解调手把手教程与MLP对比.md)。后续可以用GRU或光谱块Transformer作对照。输入统一使用C方案，不在推理时改变预处理。输出头为标准化OPD与相位sin/cos，使用atan2恢复包裹相位。

MLP验证OPD MAE约887.691 μm，相位圆周MAE约0.6389 rad。新增LSTM全局/参考点读出版本分别为95.936 μm和0.05184 rad；仅终态读出LSTM的对照效果较差，完整保留。两者训练上限100轮，LSTM主模型第42轮最佳、第62轮早停；目前都只跑一个种子。真实测试集没有读取，结果尚不足以支撑独立测量精度结论。

训练时：固定现有位置划分；仅用训练集拟合OPD标准化；OPD与相位任务分别使用有效掩码；记录至少3个随机种子、最佳验证模型和超参数。验证集用于早停及选参数，测试集仅用于冻结后的报告。

损失可先采用OPD的Huber/MSE与圆周相位损失。当前全带平均OPD和局部相位不严格满足无色散双参数余弦模型，未经检验不要强制加入过强的物理重建损失。

评价包含：OPD MAE/RMSE/偏差/P95误差；相位圆周MAE/RMSE；失败率；位置级聚合指标；独立batch=1推理延迟和批量吞吐。分别报告训练范围内与边界记录。伪标签一致性不能代替独立测量精度。

## 8. 结果、网页、PPT与文档（后续）

实验结果统一保存机器可读JSON/CSV，图表和网页读取同一份结果，避免手工填写不一致数字。网页提供CSV上传、C预处理、模型推理、传统算法对照和质量提示；输入超出已验证波段/采样条件时明确提示。

PPT按“物理问题→数据与分组→C方案→伪标签→网络→误差与鲁棒性→速度→网页展示→限制”组织。代码、参数、权重、结果和数据版本共同归档。
