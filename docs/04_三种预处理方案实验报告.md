# 三种预处理方案：实现、结果与训练输入选择

日期：2026-11-16。完成4000条原始CSV的配对比较、240条已知真值仿真控制及4组对比图。当前结论是下一阶段训练的默认输入选择，尚未证明某方案的神经网络预测精度最优。

## 1. 结论与适用边界

首轮神经网络采用A：线性插值至等波数密网格、去常量背景、抗混叠降采样至2048点、逐谱去均值和RMS归一化。不默认除包络、不默认乘Hann窗、不额外平滑。

B保留为预处理消融，C保留为FFT分析的对照。没有证据支持将“补偿＋Hann”直接固定为网络输入。本次未实现或验证温度补偿。

理由：B能改变FFT峰形，但没有明显改善共同条件下的相位拟合残差；C抵消了部分峰变窄效果。含噪仿真中，B全带宽归一化输入受到的噪声扰动约为A的6.7–6.8倍。此倍数取决于本次包络、分母下限和噪声模型，不是所有设备的普遍结论。

## 2. 三套实现

共同步骤：波长nm→m→k=2π/λ；强度同步按k升序排列；线性插值到覆盖原始范围的10001点密网格。先不缩短光谱，用同一采样分辨率比较。

| 方案 | 定义 | 意义 |
|---|---|---|
| A 基础 | uA=I−mean(I) | 去常量背景，保留原始包络与噪声结构 |
| B 背景/包络补偿 | Ahat=GaussianSmooth(I,σ=100点)；uB=(I−Ahat)/max(Ahat,0.08·max(Ahat)) | 用慢变背景作为光源包络代理；不是独立标定的条纹幅度B(k) |
| C B＋Hann | uC=uB·hann(N,sym=False) | 在B上乘周期Hann窗，观察FFT谱泄漏和相位变化 |

高斯核用于慢变背景估计，并非直接平滑最终相位或补偿温度。该参数针对现有约2.3–10.3 mm OPD数据范围；不能未经检验用于条纹极慢的小OPD数据。

原始强度单位尚未核实；不擅自把列名dBm转线性。本次补偿是对提供的数值序列进行数学比较，其物理解释在确认线性强度后才成立。

## 3. 比较如何保证公平

- 4000条全部处理；0条提取失败。15组精确重复保留于总体描述，不把4000条解释为4000个独立实验。
- 不使用距离缓存或相位标签选择滤波参数。
- 每个样本共享相位拟合支持区、权重、载波中心和侧带窗。侧带中心由共同的A×Hann粗定位得到。
- 侧带窗半宽12个FFT bin，中间平坦、两侧余弦渐变；只取正侧带，逆变换后先解调整数载波，再解包裹余相位。
- 相位拟合只用背景高于峰值15%且Hann权重大于0.2的共同区域，权重为背景相对峰值的平方。
- 参考波长固定1560 nm。OPD由中心化k坐标上的相位斜率估计，中心相位用圆周表示比较。
- FFT幅度图各自归一化至0 dB以比较峰形，不表示相同的绝对功率或SNR。
- 相位曲线显示完整载波相位；微小差异图统一减去A的拟合直线，不分别移除各自斜率，以免掩盖方法差异。

## 4. 现有数据上的结果

| 诊断指标 | A | B | C |
|---|---:|---:|---:|
| FFT振幅峰FWHM中位数，μm OPD | 51.646 | 39.886 | 51.895 |
| 共同支持区相位线性拟合残差RMS中位数，mrad | 121.498 | 122.027 | 121.533 |
| 与A的中心相位差绝对值P95，mrad | 0 | 0.0539 | 0.0625 |
| 与A的相位斜率OPD差绝对值P95，nm | 0 | 2.747 | 1.914 |

B的振幅峰宽中位数比A小约22.8%，但这只是离散FFT峰形的变化，不能解释为测量精度提高22.8%。C的峰宽回到接近A的水平，说明加窗存在有效带宽与峰宽代价。

三套流程的相位拟合残差几乎相同。原数据存在共同的非线性相位残差，来源可能涉及谱形/相位结构、量化或模型不匹配；没有温度记录或真值，不能将其归因于温漂，也不能把残差当作真实相位噪声。

方法之间的OPD和相位差很小，说明该处理在共同有效区域内没有大幅改变估计结果。但“差异小”不等于“误差小”：现有数据缺少独立相位真值，原始距离标签表也未提供，本表没有真实精度指标。

## 5. 已知真值仿真控制

仿真在原始1510–1610 nm等波长网格生成，再经过与实数据相同的流程。OPD为2.31、6.24、10.28 mm；相位包含接近±π的边界及两个内部点；每个参数组合使用5个固定噪声种子。

4种工况：无噪声、40 dB白噪声、20 dB白噪声、附加缓变背景＋40 dB白噪声。SNR相对于干涉条纹分量的全带平均平方功率定义，不包含直流包络。每工况60条配对记录，共240条；Clean工况5个种子生成相同信号，因此只有12种不同无噪声曲线。没有模拟真实温漂、散斑、探测器非线性或全部仪器效应。

20 dB工况的典型结果：

| 指标 | A | B | C |
|---|---:|---:|---:|
| OPD绝对误差中位数，nm | 13.816 | 14.224 | 13.983 |
| 中心相位圆周绝对误差中位数，mrad | 0.6288 | 0.6289 | 0.6266 |
| OPD绝对误差P95，nm | 65.734 | 65.693 | 65.732 |

传统相位提取使用共同权重和有效区域，三者表现接近，不能据小数差异宣布方法显著优越。

真正影响神经网络输入选择的是全带宽噪声敏感性：对A/B分别比较“含噪输入”和“对应无噪输入”，均经过2048点抗混叠采样及各自的RMS归一化后计算RMSE。

| 工况 | A输入扰动RMSE中位数 | B输入扰动RMSE中位数 | B/A |
|---|---:|---:|---:|
| 40 dB | 0.002855 | 0.019511 | 约6.83 |
| 20 dB | 0.028515 | 0.192434 | 约6.75 |
| 缓变背景＋40 dB | 0.002848 | 0.015375 | 约5.40 |

原因：除包络会放大弱光边缘噪声；8%的分母下限限制了增益，但不消除此效应。上述RMSE是预处理输入敏感性，不是神经网络预测误差。

## 6. 图表怎么读

- figures/01_spectrum_fft_phase：中间编号样本的原始光谱与背景、局部条纹、窗口与支持区、FFT、完整相位和统一去趋势相位。曲线接近时须结合数值表，不能仅凭视觉评价。
- figures/02_boundary_examples：首条、末条的同类比较。样本选择预先固定，不是挑最佳曲线。
- figures/03_population_diagnostics：全部4000条的经验累积分布；不将重复记录当独立重复做显著性推断。
- figures/04_synthetic_controls：已知真值误差与网络输入噪声敏感性。圆点为中位数，短横为绝对值95百分位，不是均值置信区间。

所有图提供PNG、可编辑SVG及PDF；逐样本结果见real_metrics.csv，仿真记录见synthetic_metrics.csv，汇总见summary.json，代表曲线源数据见本地trace NPZ。

## 7. 后续训练的确定流程

CSV → 单位及范围检查 → 波长转k并升序 → 10001点等k线性插值 → 去常量背景 → 多相FIR抗混叠至2048点 → 重新去均值/除RMS → float32网络输入。

保留实际重采样k坐标，不假设降采样后两端仍与原网格完全相同。逐谱归一化不需要其他样本统计量，推理时调用同一个model_input函数。

已导出本地analysis/preprocessed/model_inputs_A_2048.npz，形状4000×2048。精确重复分为3985组，使用固定随机种子20261116得到训练2800、验证601、测试599条，同一精确重复组没有跨分区。标签仍为legacy_d_mm，未冒充OPD或相位真值。

这一分组只防止精确重复泄漏，未知的批次相关性仍需元数据；本次预处理探索看过全数据，不能再把该测试集当作完全未见的最终论文验证。正式论文最好补独立日期/实验条件数据，或对选择过程采用嵌套评估。

B在后续相同网络、相同分区与相同训练预算下作为消融。C默认用于FFT分析；若将来研究Hann作为网络输入，须单独建立版本并验证，不能假定窗函数自动提高精度。当前没有训练神经网络，也没有消除温漂。

在仓库根目录执行：

```powershell

python -m pytest tests -q
python scripts/compare_preprocessing.py

```

默认数据路径为analysis/data_4000；也可通过--data-dir指定解压目录。绘图只读取比较脚本生成的结果，原始数据不随Git提交。

17项数值测试通过，覆盖OPD跨度、相位周期边界、坐标排序、插值重复轴拦截、实际降采样坐标、归一化、Hann定义和分母保护，并检验2048点网络输入仍能恢复已知OPD及相位。4组PDF均完成字体与碰撞审计并人工检查。当前使用报告/PPT尺寸、300dpi PNG预览及矢量文件，不宣称已符合某具体期刊最终版式。
