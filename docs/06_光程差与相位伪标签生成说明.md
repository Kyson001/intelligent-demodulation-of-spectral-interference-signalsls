# 光谱峰间距OPD伪标签与中心相位标签

日期：2026-11-17。传统解调先对高分辨率光谱进行预处理，再计算光程差和包裹相位伪标签。记录了多峰 OPD、局部相位和来源核对测试。

## 2. OPD为什么等于c/Δf

近似无色散模型：

I(f)=A(f)+B(f)cos[2π(f−fc)δ/c+φc]。

相邻干涉极大值的相位相差2π，因此δ·Δf/c=1，即：

```text
OPD δ = c / Δf
f = c / λ，c = 299792458 m/s，λ必须使用m
```

Δf是相邻干涉条纹峰的频率间隔，不是Δλ，也不是光频梳的梳齿间隔。实际有色散时，间隔反映局部相位斜率；全带多峰拟合得到的是有效的带内平均群OPD，不能无条件等同于几何长度。

在近正入射、均匀介质迈克尔逊中，OPD约为2nΔl。CSV中的`half_opd_m`仅为OPD/2；只有另行确认折射率、几何和零点后才能转为单程臂长差，不是镜面绝对位置。

## 3. OPD代码的逐步逻辑

1. 调用C脚本得到密波数轴、背景代理、未加窗补偿谱和加窗C谱。
2. 对C谱做FFT粗定位，估计条纹周期。这个FFT结果只用于寻峰间距设置、侧带中心和交叉检查，不替代峰间距标签。
3. 限制在背景大于峰值15%且Hann权重大于0.2的区域，避免暗边缘误峰。
4. 5点三阶SG只用于候选峰检测，结合最小距离和显著度筛峰；在未平滑、未乘Hann的补偿谱上做5点二次峰位细化。
5. 将峰位转换为升序频率，计算多个相邻间隔。若接近整数倍间隔，则显式补计可能漏掉的周期，并记录数量；不规则间隔触发复核。
6. 用稳健直线拟合峰频率与整数峰序号，斜率就是平均Δf。使用中心化频率和THz尺度改善数值条件。
7. 用c/Δf得到OPD，并保存峰数、覆盖比例、间距变异系数、拟合残差及FFT差异。

不直接使用Hann乘积的极大值：乘窗会引入幅度斜率，局部峰位可能移动。制标签用加窗谱粗定位，用加窗前的高分辨率补偿谱细化峰位。2048 点历史模型使用降采样后的光谱，当前模型使用 10001 点原始强度。

## 4. 相位标签如何获得

### 当前能够获得：中心包裹相位伪标签

固定参考真空波长λc=1560 nm，kc=2π/λc；选择正OPD支路，输出φc∈[−π,π]以及sinφc、cosφc。

算法是：C高分辨率谱 → FFT → 选正侧带 → IFFT得到复解析信号 → 去整数载波 → 解包裹余相位 → 参考频率左右各0.25 THz局部二次拟合 → 恢复参考点载波相位 → 包裹到圆周范围。

局部拟合与全带直线拟合不同。现有数据存在非线性相位结构，全带斜率/截距会受该结构影响；局部二次拟合用于估计参考点相位。输出`phase_local_opd_m`是参考点局部斜率诊断，不与全带平均峰间距OPD混为同一指标。

相位包括仪器相位零点和光路响应；没有独立标定时，不能解释成已知物理零点的绝对相位。

### 交叉检查：从峰位拟合截距求相位

若拟合写作f_j=fc+1e12·(a·m_j+b)，其中m_j是相对某个真实峰的整数序号，则：

```text
Δf = a × 1e12
φc,peak = wrap(−2πb/a)
```

利用“极大值相位为2π整数”得到第二个相位估计。它与局部解析相位不一致时保留复核标记；两种算法共享同一光谱，不构成独立真值。非线性相位下，全带截距与局部参考点相位本来就可能不同。

### 不能直接获得：无歧义绝对解包裹相位真值

不能把OPD伪标签代入φ=2πδ/λc就称为独立相位标签：这忽略未知初相位、色散和仪器相位，而且放大OPD误差。例如1 μm的OPD误差在1560 nm处对应约4.03 rad相位误差。

连续时间解包裹还要求相邻采样相位变化可辨识。名义10 μm镜面步进在空气近似下产生约20 μm OPD变化，在1560 nm处约跨12.8周期，不能直接按文件顺序unwrap恢复整周期编号。何况文件顺序/位置对应关系仍未核实。

真实相位标签需要：同步参考干涉仪、已知相移标定、可信的镜面微位移基准，或完全已知参数的仿真数据。当前先训练包裹相位的sin/cos，是不伪造整周期信息的选择。

## 5. 质量规则和本次结果

固定QC包括：至少8个峰、频率覆盖至少35%、间距CV不超过2%、与FFT粗估计相对差不超过2%、不规则间隔比例不超过5%、推定漏峰比例不超过10%；相位局部残差不超过0.10 rad，两种相位方法圆周差不超过0.20 rad。

这些阈值是筛选规则，不能解释成精度保证、概率置信度或校准后的误差限。`accepted`表示通过本套算法检查，不表示标签已被实验真值证实。

## 6. 如何运行和读取

```powershell
python -m pytest tests -q
python -X utf8 scripts/generate_pseudo_labels.py
```

标签已生成，再次重算添加`--overwrite`；调试可使用`--limit`和新的`--out`目录。默认输入`analysis/data_4000`，输出`analysis/pseudo_labels`。

| 输出文件 | 内容 |
|---|---|
| `pseudo_labels.csv` | 所有4000条标签、质量指标、算法来源和原始文件哈希 |
| `pseudo_labels.npz` | sample_ids、OPD、相位sin/cos、有效掩码及参考波长 |
| `needs_review.csv` | 8条待复核记录，原数据仍保留 |
| `training_C_with_pseudo_labels.npz` | 经ID、原始文件哈希、预处理配置核对后合并的预处理输入和伪标签 |
| `summary.json` | 参数、计数、范围、来源和限制 |
| `traces/` | 首/中/末样本实际峰位和拟合残差，供人工核查 |

读取：

```python
import numpy as np

data = np.load('analysis/pseudo_labels/training_C_with_pseudo_labels.npz')
X = data['X']                              # [4000, 2048]
y_opd = data['opd_pseudo_m']                 # 单位m
y_phase = np.column_stack([data['phase_sin'], data['phase_cos']])
opd_mask = data['opd_valid']                 # OPD损失只使用通过检查的目标
phase_mask = data['phase_valid']             # 相位损失使用单独掩码
```

不要把NaN或复核标记直接变成零标签。两个任务可分别使用mask，不必永久删除某一任务有问题的样本。计算损失前先按mask索引选择有效目标，不能只依赖NaN损失乘0，因为NaN×0仍为NaN。所有split暂为unassigned，确认“每位置10条”的文件对应关系后再按位置及重复关系分组。

## 7. 训练与论文表述边界

模型对这些标签误差小，说明它能快速逼近此套算法。真实精度评价仍需独立参考，不能以本算法作标签又证明网络真实精度超过本算法。

全带平均OPD和参考点局部相位是不同定义。后续使用物理重建损失时，必须考虑数据的非线性谱相位，不能未经检验就强制所有样本严格满足一个无色散双参数余弦模型。
