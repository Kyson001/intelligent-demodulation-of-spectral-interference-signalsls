# 绘图与独立工程代码索引

本次补齐用户修改后的可编辑PPT、此前保存在分析目录的绘图代码、独立LSTM教学工程和桌面预处理代码。数据预处理、伪标签、位置划分、MLP/LSTM训练、对比指标和已训练权重继续保存在原有目录。

## 绘图入口

以下命令在仓库根目录执行。先安装 `requirements-repro.txt`；模型对比脚本还需要 `requirements-training.txt` 中的PyTorch。

| 内容 | 代码 | 示例命令 |
|---|---|---|
| 原始光谱 | `scripts/plot_spectrum.py` | `python scripts/plot_spectrum.py 31 --save analysis/previews/file0031.png --no-show` |
| 预处理训练输入与局部条纹 | `scripts/plot_train_sample.py` | `python scripts/plot_train_sample.py --index 0 --no-show` |
| 单谱预处理四阶段 | `scripts/compare_preprocessing.py` | `python scripts/compare_preprocessing.py --index 0 --no-show` |
| 包络补偿与Hann窗 | `scripts/plot_envelope_hann.py` | `python scripts/plot_envelope_hann.py --index 0 --no-show` |
| 三种预处理配置光谱、FFT、相位及合成对照 | `scripts/plot_preprocessing.py` | `python scripts/plot_preprocessing.py` |
| MLP与LSTM误差及训练曲线 | `scripts/compare_joint_models.py` | 见下方命令 |
| LSTM纵向教学结构 | `scripts/draw_lstm_network.py` | `python scripts/draw_lstm_network.py` |
| LSTM立体神经元结构 | `scripts/draw_lstm_architecture_3d.py` | `python scripts/draw_lstm_architecture_3d.py` |
| LSTM科研风结构 | `scripts/draw_lstm_architecture_publication.py` | `python scripts/draw_lstm_architecture_publication.py` |

后三个脚本默认输出到 `results/lstm_architecture/`，可用 `--out analysis/my_figures`另选目录；含实际光谱曲线的两个脚本可用 `--data-dir`指定三份NPZ的目录。图中的光谱曲线使用训练集第一条2048点预处理输入。

```powershell
python scripts/compare_joint_models.py --mlp-run results/lstm_comparison/runs/mlp --lstm-run results/lstm_comparison/runs/lstm_center_global --control-run results/lstm_comparison/runs/lstm_last --out analysis/comparison_figures
```

`plot_preprocessing.py`读取 `results/preprocessing/` 的CSV和代表谱NPZ。若要重新计算全部原始谱的三种预处理配置指标及合成对照，运行：

```powershell
python scripts/compare_preprocessing_dataset.py
python scripts/plot_preprocessing.py
```

原来完整的批量比较入口现在名为 `compare_preprocessing_dataset.py`；用户修改后的 `compare_preprocessing.py`继续负责单条训练谱的四阶段绘图。四个本地原稿还保存在 `reference_code/local_plotting_original/`。
