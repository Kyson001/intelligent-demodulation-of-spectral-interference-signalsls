# 迈克尔逊光谱干涉信号联合解调实现方案

日期：2026-11-12。阶段：材料核查和设计；尚未训练或验证深度学习模型。最终交付为PPT、交互网页、文档、代码、图形资源及可复现结果。

## 1. 研究任务与物理定义

建议保留总题目《基于深度学习的端到端光谱干涉信号智能解调》，副标题注明“迈克尔逊干涉仪的光程差与中心相位联合估计”。

定义真空波数k=2π/λ，OPD为δ，参考波数kc附近的模型：

I(k)=A(k)+B(k)cos[(k−kc)δ+φc+ψdisp(k)]+ε(k)。

δ以米计，φc以弧度计。弱色散或已经补偿色散时，dΦ/dk≈δ；一般色散情况下拟合得到的导数对应参考点的群光程差，需另行定义。ψdisp表示高阶色散，不能无约束地与δ、φc一起拟合以免参数相互替代。

在均匀介质、近正入射迈克尔逊中，OPD≈2nΔl；空气n≈1只是近似。镜面移动Δx导致OPD变化约2nΔx。相位变化Δφc对应OPD变化λcΔφc/(2π)，镜面移动则为λcΔφc/(4πn)。

首版相位输出建议定义为参考波长处的包裹相位，范围[−π,π)。绝对解包裹相位、零点、方向及整周期编号需要额外约定。单帧光强谱并不能无条件恢复绝对相位或OPD符号。

## 2. 数据契约与准入条件

每条记录至少包含：sample_id、原始文件哈希、wavelength_nm、intensity_raw、强度单位、opd_m及来源、phase_rad及来源、参考波长、仪器/日期/批次/同源组、是否仿真。

现有距离缓存只作为legacy_d_mm暂存。原始Excel补齐并核对文件编号、物理定义、精度后，才生成训练用标签。FFT与缓存约2:1只是诊断证据。不存在的相位真值不靠文件编号猜测。

相位标签的三种路径：

- 仿真：独立生成OPD和中心相位，并保留生成参数，验证真实的两参数反演能力；另设符合光学约束的物理一致轨迹数据。
- 实测独立参考：由相移标定、参考干涉仪或已知镜面微位移建立相对相位真值，注明参考波长和初始零点。
- 传统算法：产生phase_pseudo作为辅助训练标签；测试只能声称与传统方法一致，不能证明超越该方法的真实相位精度。

仅由OPD计算φ=kcδ并不能提供独立相位验证；若数据中存在额外仪器相位、色散或未知初相位，该换算还会失效。若只有现有数据，第一版结果分为“真实标签待核实的距离回归”与“相位伪标签一致性/仿真真值评估”。

数据划分先于增强。重复谱、同一基础参数的噪声副本和同批次强相关记录按组划分；保留随机插值、未见OPD区间、跨噪声/包络、独立批次四种不同协议，不能混称泛化。没有批次元数据时明确限制。

## 3. 基线与模型

| 层级 | 方法 | 输出与目的 |
|---|---|---|
| B0 | 等波数重采样＋去背景＋加窗＋FFT | 粗OPD和可辨识性诊断 |
| B1 | B0＋峰值插值/局部拟合 | 修正栅格误差，复现P1主要思想 |
| B2 | 自适应单边频带滤波＋IFFT＋unwrap＋参考点相位拟合 | OPD及φc；滤波窗依据峰宽设置并测试边界 |
| B3 | 以FFT为初值的物理模型最小二乘拟合 | 强传统基线；报告失败与耗时，不只比裸FFT |
| M0 | 小型1D-CNN，多任务输出 | 主力工程基线，适配4000条数据 |
| M1 | 精简LSTM，多任务输出 | 与P4同类方法比较；按波长序列输入 |
| M2 | CNN＋轻量注意力＋圆周相位输出 | 候选改进；只有消融证据支持才保留注意力 |

输出头：标准化OPD、sinφc、cosφc。通过atan2得到相位，避免直接MSE在−π/π边界出错。sin/cos向量归一化并处理接近零的异常输出。

训练损失建议：L=wδ·Huber(标准化OPD误差)+wφ·[1−cos(φhat−φ)]+wphys·Lreconstruction。

重建项只在强度单位、包络、相位零点、参考坐标明确后启用；A/B等干扰参数必须受限，避免它们吸收全部误差。先证明基础监督模型有效，再添加物理一致性。时间/OPD不同量纲先归一化，不能照搬α=0.6、β=0.4。

绝对范围与精细变化分开处理：必要时先预测粗OPD，再估计参考点相位或小范围残差，经过明确的周期判定结合；粗OPD误差不足以可靠确定周期时，不宣称获得全范围纳米绝对精度。

## 4. 输入长度与计算约束

原始10001点不宜直接喂给大型LSTM或全局Transformer。先建立2048点等波数版本，同时保留原分辨率传统基线。根据实际重采样频响做抗混叠处理，测试1024/2048/4096点。

按现有1510–1610 nm范围，波数跨度约2.58×10^5 rad/m。均匀k采样时单边OPD非模糊界约π/Δk：512点约6.2 mm，1024点约12.4 mm，2048点约24.9 mm。若缓存距离确为单程距离，数据OPD上限约10.29 mm，直接缩到512点会产生混叠风险。上述是理想采样上限，不是实际仪器保证范围。

重采样不能产生原始数据中不存在的信息。确认仪器真实分辨率、光源/频梳模式与有效带宽后再设正式上限。

## 5. 训练与评价

使用固定分组清单、仅训练集拟合的标准化参数、早停和至少3个随机种子。初始使用CPU也可运行数据管线；深度学习训练视可用GPU安排。不要照搬10000 epoch，使用验证集决定停止。

| 评价对象 | 指标 | 解释 |
|---|---|---|
| OPD | MAE/RMSE/偏差、P95绝对误差、最大误差，单位μm或nm | 相对于独立/仿真真值；缓存未核实前不能作为正式指标 |
| 相位 | eφ=atan2(sin差,cos差)；圆周MAE/RMSE，单位rad或mrad | 避免周期边界假误差 |
| 精细测量 | 固定工况重复性、漂移、相对位移误差 | 与全量程准确度分开报告 |
| 可靠性 | 大误差率、失败率、歧义样本、模型外条件 | 阈值由应用需求和噪声水平制定 |
| 速度 | batch=1预热后P50/P95；批量吞吐；读入、预处理、推理分项 | GPU计时同步；单位和硬件固定，区分算法与系统速率 |

必做消融：仅OPD/联合输出；直接相位/圆周相位；有无注意力；有无重建项；不同点数；噪声/包络增强是否有效。增强在物理或原始强度域完成，波长轴改变时重新计算对应相位定义。

## 6. 候选论文问题

第一优先：采样和干扰变化下，OPD与中心相位联合解调的可靠性。研究圆周相位表示、物理一致性及多工况训练是否在相同数据预算下减少大误差和周期错误，而不仅减少随机测试集RMSE。

第二优先：粗OPD与精细相位融合的周期判定边界。研究何时能够可靠结合两者，何时必须报告歧义或需要额外参考。这比单纯“加注意力”更接近实际测量问题。

若补充实测平台，可扩展仿真到实测少标注适配。当前4篇资料不足以证明以上方向新颖，发论文前需查找最接近的Michelson联合估计与物理约束工作，并做独立实验。
