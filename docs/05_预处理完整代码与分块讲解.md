# 预处理完整代码与分块讲解

这份文档记录传统解调的光谱预处理。高分辨率版本用于生成伪标签，2048 点版本用于历史模型。当前 CNN 和 BiLSTM 直接读取 10001 点原始强度。

## 1. 应该看哪个代码文件

主文件：`scripts/preprocess_c.py`。这是独立、完整、带中文逐块注释的预处理脚本，仅依赖NumPy和SciPy；不需要运行MATLAB，不需要先执行其他项目脚本。可以批量处理现有4000个CSV，也可在训练和网页推理中调用`preprocess_spectrum()`处理一条光谱。

`src/demodulation/preprocessing.py`的`model_input(..., scheme='C')`也已支持C，用数值测试保证与独立脚本一致。这个旧接口保留默认A以兼容既有实验；当前导出入口和项目配置选择C，调用旧函数时应明确传`scheme='C'`。

## 2. 预处理步骤

原始CSV → 读入/检查 → 强度单位处理 → 波长转波数并排序 → 等波数密网格插值 → 估计慢变背景 → 扣背景 → 有下限的包络代理相除 → 乘Hann窗 → 抗混叠至2048点 → 逐谱去均值/RMS归一化 → 保存。

保留每个阶段，方便发现“某一步后条纹突然变弱”或“弱光边缘被放大”。不覆盖原始CSV，不自动生成距离或相位标签。

## 3. 每一块代码在做什么

| 代码块 | 函数/变量 | 作用与注意事项 |
|---|---|---|
| 第1块 | `CConfig` | 集中参数，检查σ、分母下限和输入长度；配置随结果保存 |
| 第2块 | `read_spectrum`、输入检查 | 读取第一列波长nm、第二列强度；检查列数、有限值和点数；不是自动把坏数据补成平滑曲线 |
| 第3块 | `intensity_unit` | 默认保持提供的数值；只有确认原始值为dBm时才显式转为线性mW |
| 第4块 | `k_raw`、`order` | k=2π/(λnm×10⁻⁹)，按k升序同步排列强度；重复波长报错 |
| 第5块 | `k_dense`、`intensity_k` | 线性插值至等波数网格，先保留10001点；范围不超过实测波段 |
| 第6块 | `background` | 用宽高斯核估计慢变背景/光源包络代理；不是直接把干涉条纹当噪声平滑掉 |
| 第7块 | `background_removed`、`envelope_corrected` | 扣背景，再用有下限的分母做补偿；弱光区域保留标记 |
| 第8块 | `hann`、`windowed_c` | 在密网格逐点乘周期 Hann 窗 |
| 第9块 | `resampled_c`、`k_model` | 多相FIR抗混叠降采样，并计算实际输出坐标；不能直接每隔5点取一个 |
| 第10块 | `X` | 逐谱去均值、除RMS，得到float32网络输入；同一函数用于训练和推理 |
| 第11块 | 返回字典 | 返回所有中间数组、坐标和质量信息；不把诊断记录叫真值 |
| 第12块 | `main`批处理 | 处理全部CSV，保存矩阵、中间样本、质量表、文件哈希和分组核对表 |
| 第13块 | `if __name__...` | 直接运行文件时启动批处理；导入函数时不会自动读取4000条数据 |

## 4. 核心公式与默认参数

背景估计：Ahat(k)=GaussianSmooth[I(k)]，σ=100个密网格点，边界使用reflect。

包络代理补偿：

```text
分母 = max(Ahat, 0.08 × max(Ahat))
补偿光谱 = (I − Ahat) / 分母
```

8%的下限用于限制小分母，不代表噪声被全部消除。背景代理也不等同于独立测量的条纹振幅B(k)。如果有校准参考谱，后续可据此改进该部分。

周期Hann（与此前比较设置一致）：

```text
w[n] = 0.5 − 0.5 cos(2πn/N)，n=0,...,N−1
C光谱[n] = 补偿光谱[n] × w[n]
```

周期Hann最后一个点不严格为零，与对称Hann的N−1分母有区别；两者不要混用。Hann作用是改变边缘权重和谱泄漏，不能当作温度补偿。

降采样使用`resample_poly`，从10001点到2048点；默认FIR抗混叠、line边界延拓。输出波数步长按实际采样率计算，不强行把两个端点都设置为原网格端点。

归一化：`X=(resampled−mean)/RMS`，每条光谱单独计算。中心化后最终边缘不再严格为零，这是归一化定义所致。若后续需要未中心化C光谱，读取`windowed_c`或`resampled_c`，不要重复乘窗。

这些参数针对当前数据条件；不得未经检查把输入缩成512点，因为可能丢失较大OPD对应的密集条纹。

## 5. 运行方法

在项目根目录的PowerShell中执行：

```powershell
python -m pip install numpy scipy
python -X utf8 scripts/preprocess_c.py
```

当前默认输入为`analysis/data_4000`，默认输出为`analysis/preprocessed_C`。也可明确指定：

```powershell
python -X utf8 scripts/preprocess_c.py --data-dir "analysis/data_4000" --out "analysis/preprocessed_C" --points 2048 --sigma 100 --floor 0.08 --intensity-unit recorded
```

`-X utf8`用于中文终端显示。原始数据的强度单位仍待确认，因此本次使用`recorded`，没有根据CSV列名盲目转换。

只有确认原始值确为dBm后，才使用`--intensity-unit dbm`。更改单位/参数时建议使用新的`--out`目录，以免混淆结果。确需重跑覆盖时添加`--overwrite`。

默认只保存首条、中间条、末条的完整中间数组；若需要每条都保存，添加`--save-all-stages`，会增加磁盘空间占用。

## 6. 输出文件怎么用

| 输出 | 内容 |
|---|---|
| `model_inputs_C_2048.npz` | `X`、实际k坐标、sample_ids、精确重复组、归一化参数；当前不含伪造真值 |
| `manifest_C.json` | 预处理配置、形状、质量状态、文件哈希、分组待确认状态 |
| `quality_and_position_review.csv` | 每条的强度范围、背景峰值、弱光比例、归一化参数及位置核对列 |
| `stages/file0001_C_stages.npz`等 | 原始输入、等k光谱、背景、补偿谱、Hann、加窗谱、降采样谱及网络输入 |

加载网络输入：

```python
import numpy as np

data = np.load('analysis/preprocessed_C/model_inputs_C_2048.npz')
X = data['X']                         # [4000, 2048]，float32
k = data['k_rad_per_m']               # [2048]，对应X的真实波数坐标

X_lstm = X[:, :, None]                # 常见LSTM格式：[样本, 序列长度, 特征]
```

## 7. 每位置10次重复如何处理

已知每个采集位置有10组，但尚未确认文件排列是否严格按位置连续保存，因此不擅自把每10条当真位置，也不沿用此前只按精确重复划分的方法。

质量表的`order_block_candidate`只是每10条的顺序候选块；`position_id_confirmed`留空供核对。输出矩阵的`split`均为`unassigned`。核对位置后再按位置及重复关系统一分组，避免相同位置同时出现在训练集和测试集。预处理本身不依赖标签和分区，可以先完整完成。
