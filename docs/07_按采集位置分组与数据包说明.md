# 每位置10条的核查、无组泄漏划分与桌面交付

日期：2026-11-17。目标：验证顺序假设、形成逐条分组清单，以位置为单位划分，并将数据和中文注释代码放入桌面文件夹。

## 1. 是否从file0001起每10条连续排列

采集说明为每位置10条、名义镜面步长10 μm。现有文件编号file0001至file4000连续完整，形成400个候选位置：

- P0001：file0001–file0010；P0002：file0011–file0020。
- 以此类推，P0400：file3991–file4000。

使用谱峰间距OPD伪标签作诊断，考察相邻差，并将分块起点错开0–9条做对照。只有0偏移具有明确的组间阶跃：

| 诊断 | 结果 |
|---|---:|
| 组内相邻OPD差中位数 | 约0.2196 μm |
| 跨10条边界的相邻OPD差中位数 | 约19.9541 μm |
| 边界/组内比 | 约90.87 |
| 其余1–9条偏移的比值 | 约0.76–0.94 |
| 相邻位置OPD中位数阶跃P5/P50/P95 | 约17.93/20.07/21.94 μm |

FFT幅度形状的相邻余弦距离中位数，组内约0.000201、边界约0.213969，也支持该顺序。这种形状诊断弱化了单纯相位移动对直接光谱相关性的影响。

约20 μm的OPD阶跃与迈克尔逊约10 μm镜面名义步进相符，但不能把名义步长当精确真值。结论为：数据强烈支持按连续10条形成候选采集位置，足以用于本次分组；没有硬件位置日志独立证明每个文件的物理位置。

## 2. 发现的异常如何处理

15组精确重复中，3组跨候选位置：

| 文件 | 涉及位置 |
|---|---|
| file0090 / file0091 | P0009 / P0010 |
| file1450 / file1451 | P0145 / P0146 |
| file3060 / file3061 | P0306 / P0307 |

将这3对位置各自绑定到同一分区，防止跨位置重复落入训练和测试两边。400个位置形成397个不可拆分组件，但统计位置数仍为400，不把两个名义位置改称一个真实位置。

另以“OPD与本位置中位数相差>5 μm”作提示，标记file0083、file0091、file0951、file1451、file3061共5条。其中3条正好是跨位置重复涉及的下一组首条，可能是帧重复或采集过渡，但不凭诊断自动改文件位置。其余异常也不能仅据伪标签诊断认定为仪器错误。

这些标记与既有8条伪标签QC复核记录分别保存，有2条重叠，总计11条不同记录需要至少一种复核。全部4000条保留，原OPD/相位有效掩码不被改成零标签。

## 3. 位置级70/15/15划分

随机种子20261117，使用位置和精确重复关系分配，不按伪标签误差挑选测试样本。用子集和分配不可拆分组件，达到精确比例：

| 分区 | 位置数 | 光谱数 |
|---|---:|---:|
| train | 280 | 2800 |

同位置10条不跨分区，完全重复谱也不跨分区。此次属于随机留出未见位置的同次采集评估，以插值为主，并包含少量训练OPD范围外的边界样本；汇总中分别计数。不将其表述为专门设置的连续区间外推或跨日期/设备测试。

实际验证集与测试集各有10条OPD估计位于训练范围以外的边界样本，未为使结果更好而事后挪组。

## 4. 桌面文件夹内容

```text
迈克尔逊光谱_C方案_分组数据集_20261117/
  README_使用说明.md
  datasets/
    train/        processed_C_with_pseudo_labels.npz、samples_and_labels.csv、raw/
    validation/   processed_C_with_pseudo_labels.npz、samples_and_labels.csv、raw/
    test/         processed_C_with_pseudo_labels.npz、samples_and_labels.csv、raw/
  grouping/       逐条清单、位置清单、错位检验、重复清单、复核清单和汇总
  code/           中文注释预处理/制标签/划分脚本、核心模块、参数和测试
  docs/           预处理、伪标签和本说明
  source_artifacts/full_C_with_pseudo_labels.npz
```

原始CSV通过内容复制放入对应raw目录，源文件未移动或删除，也没有用共享硬链接。复制前后核对SHA256。保留全量处理后源包供完整复现，避免只能拿到分区后无法重新核查。

每份NPZ都包含X、OPD/相位伪标签、sin/cos、任务有效掩码、位置、重复序号、位置异常提示、分区和重复绑定组件。OPD单位m，中心相位参考波长1560 nm，X为float32、每条2048点。

## 5. 核查与复现

主代码：`scripts/split_dataset_by_position.py`，函数分别负责顺序诊断、重复位置绑定、组件分配、桌面打包和报告生成。

```powershell
python -m pytest tests -q
python -X utf8 scripts/split_dataset_by_position.py
```

输出目录必须是新目录，防止覆盖既有桌面数据。可用`--out`指定另一个新目录。测试检查位置数、精确重复不泄漏、相同种子确定性，以及错误顺序被门槛拒绝。

桌面包生成后已独立验证：三份数组、标签和掩码逐条与源包一致；4000个原始CSV的复制内容SHA256复核通过；位置与精确重复谱均无跨分区交集。直接在桌面包的code目录运行，41项测试通过。

当前预处理为逐谱操作，不使用全体样本拟合的归一化统计量。不过预处理选择阶段曾观察全数据，所以这些分区可用于课程项目内部开发，正式论文仍需独立参考/补采测试，不能将本次伪标签一致性报告为独立测量精度。
