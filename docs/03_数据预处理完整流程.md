# 迈克尔逊光谱干涉数据预处理完整流程

日期：2026-11-16。状态：预处理协议，尚未确定降噪参数、生成正式训练集或验证模型精度。

## 目标与已知事实

目标是保持OPD和相位信息，而非使曲线尽可能平滑。已审计4000条光谱，每条10001点、1510–1610 nm；15组精确重复。强度列名dBm与实际数值形式需要确认；原始Excel标签未提供，缓存距离及相位来源未核实。当前不能认定噪声种类、真实SNR或所有零值含义。

## 总流程

只读归档与清单 → 单位/标签/波长轴核查 → 同源分组并冻结数据划分 → 训练集噪声与有效波段分析 → 按冻结规则清洗 → 校准/背景处理 → 波长转波数与密网格插值 → 可选保相位降噪 → 抗混叠降采样 → 各算法分支处理 → 训练用增强与归一化 → 标签编码 → 输出与验收。

确定性文件检查和重复识别可以在划分前完成；凡会选择波段、滤波参数、归一化统计量和模型超参数的操作，只能使用训练/验证数据，测试集仅在最后按冻结协议评价。

## 1. 归档和数据清单

保留原始RAR、CSV、MATLAB文件和PDF。记录文件哈希、sample_id、单位、标签来源、日期、设备、分组和处理版本。原始数据不覆盖；历史_cache只做辅助核对，不作为唯一可信输入。

## 2. 强度、标签及物理约定

- 波长nm转换为m，统一参考波数kc/参考波长λc，不因每个样本的噪声峰移动而改变参考点。
- 只有确认原值确为dBm，才按P_mW=10^(P_dBm/10)转换到线性功率；若已是线性/归一化数据则不转换。
- 已有精确零不等于缺失值或坏点，不直接填补、取对数或删除。
- legacy_d_mm先保留原名，老师确认单程/双程定义后再生成opd_m。当前FFT诊断约2:1只是推断依据。
- 相位区分独立真值、仿真真值和传统算法伪标签。统一包裹范围及零点，不从OPD推算后称为独立相位真值。

## 3. 数据质控及分组

检查非有限数、波长重复/不单调、缺行、列数、饱和、常数谱、断裂及异常毛刺。按物理阈值标记，记录理由；低SNR但有效的样本保留为困难样本。仅在孤立坏点确有证据时局部修复并保存mask；连续缺失不能伪造完整光谱。

15组精确重复必须同组划分；也可按预定规则只保留代表样本并保存重复映射。近重复、同位置重复测量、同一仿真基谱、连续扫描批次需进一步识别；文件编号邻近不自动证明时间邻近。

建议按组约70/15/15划分训练/验证/测试，比例可调整。同源组不能拆开；条件允许时另外冻结未见OPD区间、独立日期或跨噪声测试。无法识别批次时明确实验限制。

## 4. 噪声分析先于去噪

| 现象/来源 | 诊断 | 处理原则 |
|---|---|---|
| 探测电子噪声/背景 | 暗场、同工况重复测量、背景区 | 有参考数据时做暗场校正；不能假设均为白噪声 |
| 光源包络/强度漂移 | 参考谱、低频背景、重复测量 | 背景扣除或受限包络建模；不要把背景与噪声混为一谈 |
| 孤立尖峰 | 局部残差、空间孤立性、仪器记录 | 只修复确认坏点，避免把真实条纹峰当尖峰 |
| 波长标定/抖动 | 参考谱线和仪器校准 | 校准坐标，保留不确定度；逐点随机加噪声不能替代轴抖动 |
| 相位噪声/机械波动 | 固定工况重复测量与时间信息 | 普通强度平滑无法保证消除此类误差 |
| 量化/截断 | CSV保存精度、零值分布、饱和 | 已损失的信息不能靠插值恢复 |

若有同一工况、独立且同方差的重复测量，可由差分估计随机噪声方差：Var(I1−I2)/2。含真实相位变化或漂移时，此量不再是纯探测噪声。

无重复测量时，可在等波数域利用物理拟合残差或延迟域侧带外能量构造噪声代理指标，但必须注明模型误差、谱泄漏及滤波带宽的影响，不能把代理值称作真实SNR。直接std(I)或相邻差分会混入真实干涉条纹，不宜作为噪声标准差。

分析原始数据的噪声后才能确定增强分布；不预先认定5–40 dB适用。插值与滤波会使噪声相关，需记录噪声指标在哪个处理阶段计算。

## 5. 有效波段、校准与背景

现阶段先保留1510–1610 nm，以训练数据/参考谱分析边缘是否存在稳定低响应、截断或坏点。若裁剪，所有数据采用同一固定波段，重新计算非模糊范围，保证kc位于有效区间。

有暗场/参考强度时先按仪器定义校正。平场除法使用有效响应掩码和分母下限，避免暗区放大噪声。没有参考谱时不伪造暗场。

背景A(k)和条纹幅度B(k)不同；减均值只去常量，不能自动去除光源包络。需要背景估计时，在统一k域采用比最长条纹周期明显更慢的背景模型，并验证小OPD的慢条纹未被扣除。首版学习分支保留校正强度谱，背景扣除作为对照，避免预处理提前丢失有用信息。

## 6. 等波数密网格

k_i=2π/(λ_i×10^−9)，随后按k升序对强度和坏点mask同步排序。建立固定等间距密网格，首版保留10001点并限制在实测覆盖范围，不外推。

线性插值作为基线，PCHIP/三次样条作为对照；插值核可能改变振幅和相位，不预设高阶一定更好。保存实际坐标数组、端点、步长与插值方式。输入是仪器强度读数重新参数化，不因坐标变化就无条件乘谱密度Jacobian；若数据确实定义为每单位波长/频率的谱密度并需积分能量比较，再按其定义转换。

## 7. 可选降噪

默认不做额外平滑，保留原噪声基线。针对尖峰的局部修复、轻量SG、小波或侧带滤波均是待比较方法，不串联全套滤波。

条纹周期T_k≈2π/|OPD|。平滑窗口必须依据最短条纹周期及通带响应选取，不能无视OPD范围固定设置很宽的窗口。尤其压缩后每周期点数变少，窗口不能照搬10001点版本。

对称/零相位滤波只是在指定条件下避免系统线性时延，并不保证无边界效应、无幅度失真或相位估计偏差。滤波验收必须看OPD及圆周相位误差，不只看曲线与SNR。

## 8. 抗混叠降采样

在等波数密网格上先低通，再按目标网格采样；记录边界延拓、滤波器及输出k坐标。多相FIR重采样可作为实现方案，输出坐标按实际输入输出采样率生成，不能仅用linspace假设两端严格相同。

首版网络2048点，验证1024/2048/4096点；传统基线同时保留10001点结果。按完整波段，512点理想OPD上限约6.2 mm；现有缓存若为单程距离则OPD最高约10.29 mm，512点存在混叠风险。抗混叠滤波只能移除超出带宽的信号，不能让512点仍无损保留这些条纹。

## 9. 分支处理

传统FFT分支：去背景/直流→加窗→FFT→峰定位与插值，保留谱泄漏和峰宽信息。相位分支：有效侧带选择→逆变换解析信号→低幅度掩码→必要的unwrap→参考点稳健相位拟合。弱幅度和边界区域不强行拟合；报告失败。

FFT返回的解析相位若参考k_min，转换中心相位时φc=wrap[φ_start+δ(kc−k_min)]，并核对正负侧带符号约定。用已知相位合成信号验证，不依靠肉眼调整常数。

学习分支默认输入未加窗的统一网格强度；去背景/包络归一化作为可追踪对照。unwrap、FFT和相位拟合不是训练输入必需步骤；若加入FFT特征，应明确称作物理特征辅助版本。

## 10. 增强和标准化

训练集在物理/线性强度域增强，再经过同一插值、滤波、降采样和归一化流程。可探索加性噪声、全局增益、缓慢包络变化、少量坏点和真实标定幅度内的波长扰动。相位或OPD改变时必须同步更新标签，波长偏移不能简单平移光谱却沿用不兼容的相位真值。

验证/测试不随机增强，鲁棒性测试另建固定扰动集并保存种子。原有样本并非干净信号，追加噪声时只能先说明“新增噪声功率”，不能未经基底噪声估计就宣称达到某个总SNR。

首版可比较逐谱去均值/标量尺度归一化，以及训练集拟合的全局标准化。逐谱操作不需要跨样本拟合，但推理时必须相同；若使用逐点训练均值方差也需冻结并检查低方差边缘。不能拿整个4000条求统计量。保存尺度等元数据，后续研究强度相关不确定度时仍可利用。

## 11. 标签与输出

OPD统一以米保存，用训练集统计量标准化供损失计算，展示再转μm/mm。包裹相位编码为(sinφc, cosφc)。伪标签含来源、质量标志、置信度，不冒充真值。没有相位标签时先用合成数据验证，或只报告传统算法一致性。

输出建议：X_calibrated、X_k_dense、X_model、k_grid、sample_id、group_id、split、opd_m、phase_sin/cos、label_source、quality_mask，以及配置、哈希、标准化参数。用npz/hdf5等无损格式避免反复文本舍入；几何和相位拟合使用float64，神经网络输入可验证后使用float32。

## 12. 验收

1. 合成已知OPD/φc信号覆盖完整范围、相位边界及噪声条件；在原始λ网格生成再走全流程。
2. 逐步比较插值、去背景、降噪和降采样引入的OPD偏差、圆周相位偏差和条纹幅度变化。
3. 在同一冻结测试协议比较不平滑/轻度平滑/其他候选，只根据训练验证选参数。
4. 重复和同源组无跨分区；最终测试集保持完整，失败样本不事后删除。
5. 保存采样范围、单位、相位参考、版本、模型和网页一致性记录；没有独立真值时不报告真实测量精度。

## 建议第一版配置

原始全波段保留；单位未明时不做对数转换；分组后训练；10001点等k密网格；不做额外平滑；需要时受限去背景；抗混叠到2048点；固定尺度归一化；OPD与圆周相位输出。以对照实验决定是否加入降噪。
