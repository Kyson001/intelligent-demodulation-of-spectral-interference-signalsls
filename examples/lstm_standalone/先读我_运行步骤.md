# LSTM光程差与相位联合解调：一步一步运行

你现在打开的就是完整的独立工程。当前电脑的运行环境已经准备好，可以直接从下面第1步开始。代码和数据都在本文件夹中，不需要打开原来的大项目。

## 一、先认识文件

```text
LSTM光程差相位联合解调工程/
├─ model.py                 整个LSTM网络结构
├─ train.py                 训练入口，同时包含数据读取、损失、验证和保存
├─ requirements.txt         依赖包版本
├─ 先读我_运行步骤.md        本说明
├─ data/
│  ├─ train.npz             训练集：2800条，280个位置
│  ├─ validation.npz        验证集：600条，60个位置
│  └─ test.npz              测试集：600条，60个位置
└─ .venv/                   已准备好的本机Python运行环境
```

训练后会自动多出`outputs/`，里面每次训练创建一个带日期时间的新结果文件夹。首次打开没有`outputs/`是正常情况。

运行Python后也会自动出现`__pycache__/`缓存目录，可以直接忽略。

NPZ是保存多个数组的数据文件。每条输入是2048点预处理后的光谱，文件中还保存OPD标签、相位sin/cos、有效标签标记和采集位置编号。OPD和相位都是算法伪标签，误差表示与伪标签的一致性。

## 二、第1步：打开PowerShell并进入工程

按`Win + R`，输入`powershell`，按回车。将下面整行复制进去，再按回车：

```powershell
cd 'C:\Users\Kyson\Desktop\LSTM光程差相位联合解调工程'
```

接下来所有命令都在这个窗口中运行。每次重新打开终端，先执行一次这条`cd`命令。

## 三、第2步：检查运行环境

```powershell
.\.venv\Scripts\python.exe -c "import numpy, torch; print('NumPy:', numpy.__version__); print('PyTorch:', torch.__version__)"
```

预期包含`NumPy: 2.1.3`和`PyTorch: 2.15.0+cpu`。`cpu`表示当前使用CPU版本，当前LSTM可以直接训练；本机有显卡也无需为第一轮实验更换环境。

这里始终使用`.venv`里的Python，不需要手动激活环境，也不用修改PowerShell执行策略。

## 四、第3步：先运行2轮，确认能训练

```powershell
.\.venv\Scripts\python.exe -X utf8 train.py --epochs 2
```

这条命令就是“启动整个工程的训练”。它会自动：读取训练/验证NPZ → 检查分区 → 建立LSTM → 计算损失并更新权重 → 验证 → 保存结果。

你会看到类似内容：

```text
工程位置：...
本次输出：...\outputs\train_日期_时间
设备=cpu；参数量=23,427；训练=2800；验证=600
Epoch 001 | train=... | val=... | val_OPD=... | val_phase=...
最佳轮次=...；验证OPD MAE=... μm；相位圆周MAE=... rad
```

2轮只是检查运行流程，不能拿它的误差作为正式性能。`train`表示训练损失，`val`表示验证联合损失；损失值本身没有直接的μm或rad单位。

## 五、第4步：正式训练，最多100轮

2轮成功后，执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 train.py --epochs 100
```

默认批量64、学习率0.001、8点一个光谱块、每方向32个隐藏特征、1层双向LSTM、相位损失权重1。若验证损失连续20轮不改善，会自动提前停止，因此没跑满100轮也可以正常结束。

每次执行都会创建一个新的带时间的输出目录。终端打印的“本次输出”就是本轮结果的位置，请找到该目录。

如果训练过程中需要中断，可在终端按`Ctrl + C`。当前代码没有断点续训功能，重新运行会开始一次新训练。

## 六、第5步：查看结果

打开本轮的`outputs/train_日期_时间/`：

| 文件 | 作用 |
|---|---|
| `best.pt` | 最佳模型，包含权重、网络设置和OPD标准化参数 |
| `config.json` | 这次训练用的参数、依赖版本、数据SHA256 |
| `history.csv` | 每轮训练/验证联合损失与两个任务各自的损失 |
| `validation_metrics.json` | 验证集上的光程差误差和相位圆周误差 |
| `validation_predictions.csv` | 每条光谱的预测、标签、位置和误差 |

CSV可以用Excel打开，JSON可以用记事本或VS Code打开。先在`validation_metrics.json`中找：

- `opd_um_mae`：光程差平均绝对误差，单位μm。
- `phase_rad_mae`：相位圆周平均绝对误差，单位rad。
- `best_epoch`：保存的最佳模型来自第几轮。
- `epochs_run`：实际上训练了多少轮。

本工程使用此前验证较好的“全局＋参考点读出”LSTM。相同数据、版本和设置下，此前100轮上限实验得到OPD MAE约95.936 μm、相位圆周MAE约0.05184 rad；不同环境可能有数值差异。这些是伪标签一致性，不是独立仪器精度。

## 七、代码按什么顺序读

先只读两个位置：

1. 打开`model.py`，搜索`def forward`：看光谱如何变成OPD和相位预测。
2. 打开`train.py`，搜索`def train`：看读取数据、建立网络、训练、验证和保存。

`train.py`前面的函数为这段训练流程服务，按中文标题分成八部分。可随后阅读`joint_loss`理解损失，阅读`SpectralDataset`理解每批标签。

网络的维度变化：

```text
[B,2048]光谱
   → [B,256,8]连续光谱块
   → 双向LSTM：[B,256,64]
   → 全局均值、全局标准差、1560 nm参考点特征：[B,192]
   → 共享全连接层：[B,64]
   ├→ OPD头：[B]
   └→ 相位头：[B,2]，顺序sinφ、cosφ
```

每条光谱独立编码，隐藏状态不跨样本传递；同位置10条重复谱没有被拼成时间序列。读取参考点只使用波数坐标，不读取标签答案。

## 八、如何修改训练参数

先学会一次只改一个参数。例如降低学习率：

```powershell
.\.venv\Scripts\python.exe -X utf8 train.py --epochs 100 --lr 0.0003
```

例如改批量大小：

```powershell
.\.venv\Scripts\python.exe -X utf8 train.py --epochs 100 --batch-size 32
```

查看全部可调整参数：

```powershell
.\.venv\Scripts\python.exe -X utf8 train.py --help
```

## 九、测试集什么时候使用

普通训练只读取`train.npz`和`validation.npz`。结构和参数确定后，才用`--evaluate`评价一次测试集，例如：

```powershell
.\.venv\Scripts\python.exe -X utf8 train.py --evaluate --checkpoint 'outputs\你的正式训练目录\best.pt'
```

把“你的正式训练目录”替换成实际目录名。该命令会创建`outputs/evaluate_日期_时间/`，导出测试指标和逐条预测。不要依据测试结果反复修改超参数。工程整理验证没有执行真实测试集评价。

## 十、换电脑时重新准备环境

当前`.venv`已在本机准备好，包含CPU版PyTorch，并复用本机基础Python已有依赖；它不是可直接跨电脑搬运的运行环境。把工程代码和data移到新电脑后，在工程根目录重新创建环境并安装依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

当前实际验证平台是Windows、Python 3.13.5、NumPy 2.1.3、PyTorch 2.15.0+cpu。
